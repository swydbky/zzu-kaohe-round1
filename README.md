# 15 道 C 语言考核题

郑州大学电控组招新考核（第一轮）。两批共 15 题，每题一个文件夹：`qN.c` 是源码，`qN.png` 是 VS Code 里编译运行的截图。

代码里注释写得比较啰嗦——每个符号、格式符、关键字为什么这么写都标了出来，纯属给自己复习用，不是标准答案，仅供参考。

## 怎么编译运行

单文件：

```bat
gcc q1.c -o q1
q1.exe
```

第二批第 5 题是三个文件，要一起编译：

```bat
gcc main.c e.c -o e
e.exe
```
